# EVE Retroindustry — Chaquopy Android PoC

Goal: verify that the app's entire Python dependency stack starts up on Android
(via Chaquopy = CPython runtime in the APK). **The make-or-break is `pydantic-core`
(Rust binary)** — if it imports, the rest is straightforward work.

The running app shows a report like:

```
EVE Retroindustry — Chaquopy dependency PoC
Python 3.12.x on x86_64
--------------------------------------------
  OK   fastapi        0.115.0
  OK   pydantic       2.9.2
  OK   pydantic_core  2.23.4      ← this is the key line
  OK   sqlalchemy     2.0.35
  ...
  OK   FastAPI + pydantic model/validate works
  OK   sqlite3 read/write works
```

If `pydantic_core` shows FAIL, we deal with it (pin an older FastAPI with pydantic v1,
or replace pydantic in our few Form endpoints).

---

## 1. Toolchain on CachyOS (nothing installed yet)

The simplest option is **Android Studio** (it brings the SDK, emulator, and AVD management):

```bash
# Android Studio + JDK (needed for Gradle/AGP)
paru -S android-studio jdk17-openjdk        # or: yay -S android-studio
# on first launch Studio downloads: Android SDK, platform-tools (API 34).
# we DON'T NEED a system image / emulator — testing is done on a physical phone.
```

After installing, set up the env (add to ~/.zshrc):

```bash
export ANDROID_HOME="$HOME/Android/Sdk"
export JAVA_HOME="/usr/lib/jvm/java-17-openjdk"
export PATH="$PATH:$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator"
```

CLI-only variant without Studio: `paru -S android-sdk android-sdk-platform-tools
android-emulator jdk17-openjdk` (from AUR; longer build).

---

## 2. Testing — on a physical phone (no emulator)

We target **only `arm64-v8a`** (real phones). We don't use the emulator, so the
APK contains no x86_64 and wouldn't start in an emulator — that's intentional.

Phone over USB (USB debugging enabled in Developer options):

```bash
adb devices                            # verify the phone is visible
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.everetro.poc/.MainActivity
adb logcat -s python.stdout python.stderr
```

Without a cable: transfer the APK to the phone and install it manually (allow
"install from unknown sources" for the app).

---

## 3. Build + install the PoC

```bash
cd android-poc
# the Gradle wrapper is generated by Studio itself, or:
gradle wrapper        # if you have a system gradle (paru -S gradle)

./gradlew assembleDebug                # first build downloads Python + wheels (takes a while)
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.everetro.poc/.MainActivity
# you'll see the report in the app; or the log:
adb logcat -s python.stdout python.stderr
```

The first build is slow — Chaquopy downloads CPython 3.12 for Android and all the
wheels (incl. pydantic-core). When it passes and the app shows all `OK`, the stack
is verified and we can plan the full port.

## What next, once the PoC passes

1. Instead of `poc.py`, the real `app/` (FastAPI) gets bundled and uvicorn is
   started on `127.0.0.1:8000` in a thread (like pywebview on desktop).
2. Instead of a TextView, MainActivity shows a `WebView` pointing at `http://127.0.0.1:8000`.
3. OAuth: loopback redirect (`127.0.0.1`) works the same as on desktop.
4. Data (`eve_cache.db`, SDE, tokens) in app-private storage = on the user's device.
